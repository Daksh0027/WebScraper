API Documentation.

POST /api/scrape
Parameters
url string · required
The target domain or full URL to analyze.
backend string · optional
"auto" (default), "urllib", or "playwright".
cURL Example
curl -X POST /api/scrape \
  -H "Content-Type: application/json" \
  -d '{"url": "github.com"}'
"site_url": "https://github.com", "summary": "The web's most-used online collaborative development...", "what_it_does": "Platform for version control and collaborative...", "what_it_sells": "Developer tools and hosting", "theme": "technology", "keywords": ["git", "development", "collaboration"], "page_count": 12 }, "pages": [ { "url": "https://github.com", "title": "GitHub: Where the world builds software", "headings": ["Build software better", "..."], "links": ["/features", "/pricing", "..."], "text": "GitHub is where over 100 million developers..." } ], "crawl_backend": "urllib" }

Response (Error)

{
  "error": "Scraper error: Connection timeout"
}

HTTP Status Codes

200 OK
Scrape completed successfully
400 Bad Request
Invalid URL or parameters
500 Internal Server Error
Scraper encountered an error
502 Bad Gateway
Site may block automated browsing

💻 Code Examples

JavaScript/Fetch

const response = await fetch('/api/scrape', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    url: 'github.com',
    backend: 'auto'
  })
});

const data = await response.json();
console.log(data.analysis.site_name);
console.log(data.pages.length);

Python/Requests

import requests

response = requests.post('/api/scrape', json={
    'url': 'github.com',
    'backend': 'auto'
})

data = response.json()
print(data['analysis']['site_name'])
print(f"Pages found: {len(data['pages'])}")

cURL

curl -X POST http://localhost:5000/api/scrape \
  -H "Content-Type: application/json" \
  -d '{"url": "github.com", "backend": "auto"}'

📊 Response Fields

site_name - Name of the website
summary - Brief description of the site
page_count - Total crawlable pages found
theme - Detected site category (technology, ecommerce, etc)
keywords - Extracted keywords from content
pages - Array of crawled page objects with URL, title, content, links
crawl_backend - Which backend was used (urllib or playwright)
